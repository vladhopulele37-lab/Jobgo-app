# Jobgo-app 🚀

> If you want to start to work or to find the perfect job for you.

Jobgo is a simple, fast and clean web app designed to help people find their first job or their dream job.

### 🎯 What is Jobgo?
Clean and easy to use, fast search, focused on finding work.

### 🛠️ Tech Stack
- HTML5, CSS3, JavaScript
- Hosting: GitHub Pages

### 🚀 How to run
Clone and open index.html
